# Part association

A typed association from an originating Part to another Part.

## Information kept

- **Association type** — The source-declared association type.
- **Other type description** — The description of a custom association type.
- **Comment** — The association comment.
- **Originating Part assignment** — The Part from which this association originates.
- **Other Part assignment** — The Part referenced by this association.
- **Added at** — When this record was added.
- **Modified at** — When this record was last modified.
