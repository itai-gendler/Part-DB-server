# Add stock — Authenticated Web primary

## Trigger

The caller requests addition of two units to a known existing quantity and supplies a comment.

## Outcome

The accepted addition increases the saved quantity of the selected known lot.

## Edge cases

- Helper failures do not imply locking, race-free accounting or atomic rollback.
- An omitted MCP comment becomes an empty string; Web omitted-comment boundaries are separate cases.
