# Stocktake part lot — Corresponding omitted-comment path (Public Web)

## Trigger

The caller submits a direct nonnegative stocktaking request without the comment field.

## Outcome

The direct Web omitted-comment request can fail after in-memory helper effects; a successful saved adjustment or rollback is not promised. MCP converts its omitted comment to an empty string.
